Using pirep

Open a folder, read what you have not read. This page describes what is on the screen, nothing more.

ON THIS PAGE
Getting started Reading queue Changes File types Shortcuts Settings

Getting started

There is nothing to sign up for. Pick a folder with markdown in it and that folder becomes your Base.

1
Install pirep
Open the downloaded file and move it to your Applications folder.
2
Pick a folder
On first run you can create a new Base or open a folder that already holds markdown.
3
Read once indexing finishes
pirep walks the folder once to build the list. It does not modify your files.

You can change your Base later in Settings › Base. Only one Base can be open at a time.

Reading queue

The sidebar has two modes. QUEUE shows only what is left to read; FILES shows your folder structure as it is.

UPDATES Notes whose contents changed since you last read them, with the current version and last edit time.
UNREAD Notes you have never opened. Reading one takes it out of the list.
PINNED Notes you pinned yourself. They stay even after you read them.
RECENT Recently opened notes, read or not.

Drag the sidebar edge to resize it. On a narrow window it opens as a drawer instead.

Changes

pirep remembers the last version you read of each note. When the file on disk differs from it, that note becomes an update.

HOW IT DECIDES
✓ Reading a note in the app marks that version as the one you read.
✓ Another editor or an AI tool saving the file creates a new version. When saves come in bursts, pirep waits 0.4s and records once.
✓ Only the lines that moved between your read version and the current one are shown. The update stays until you accept or dismiss it.

Press ⌘U to gather every changed note and work through them at once. Snapshot retention is set in Settings › Version history.

File types

The colour of the chip beside a filename says what pirep can do with the file, not what the extension is.

MD NATIVE
pirep’s own format. Read it, edit it, track its versions.
md · markdown · mdx
PDF READABLE
Viewable in the app. No editing, but versions are still tracked.
html · pdf · csv · txt · json · yaml · png · jpg · svg
PPTX· OPAQUE
pirep cannot open it. Clicking hands it to the app you normally use.
pptx · docx · xlsx · zip · everything else

Settings

Eight tabs.

Appearance Theme, reading width, default sidebar mode, interface language.
Editor Wrapping, autosave, and how pasted text is handled.
Base See the folder that is open and switch to another one.
Version history Whether to keep snapshots and for how long. Turning it off stops read tracking.
Templates Manage note templates and the rules that create notes automatically.
Account & Sync Tells you whether your Base already sits in a synced location. pirep never uploads your files.
Shortcuts The full keymap — the same table as above.
About Version and update check.

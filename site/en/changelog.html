What changed, by version

Also available in the app under Settings › About.

0.4.2 2026.09.08 LATEST

The reading queue and the changes view were rebuilt. Files are now sorted into three tiers by what pirep can do with them, and the whole interface was reset around the light theme.

ADDED
+ Knowledge Inbox — today’s date alongside changed notes and notes you have not read yet, on one screen.
+ Review changes (⌘U) — accept or dismiss updates across several notes in one pass.
+ File type chips — markdown, files the app can display, and files it cannot open are told apart by colour.
+ HTML · PDF · CSV · image viewers — non-markdown files now open inside the app.
+ Tag results and Rabbit Hole — gather notes by tag, and keep the trail of what you read next.
+ Eight settings tabs — Editor, Version history, Templates and Account are now separate.
CHANGED
· Light is now the default theme. Dark is chosen in Settings › Appearance.
· The sidebar can be resized by dragging its edge.
· The note path moved to the centre of the title bar. Clicking a folder name jumps to that folder.
· Search moved to the top of the sidebar.
· ⌘R still opens Related Topics. Mark as read is now ⌘⇧R and mark all read is ⌘⌥R.
· The interface is English only for now. Korean is on the way.
FIXED
· Some edits were missed when saves arrived in bursts. pirep now waits 0.4s and records once.
IN PROGRESS
▫ Presenting HTML and PDF as slides
▫ Editing a single line as raw markdown
▫ Handling the case where the app and another editor changed the same line
▫ PDF page navigation
▫ Windows and Linux builds

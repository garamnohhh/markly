LOCAL-FIRST

파일은 내 컴퓨터에 있어요

pirep은 폴더를 열어서 읽어요. 파일을 서버로 보내지 않고, 형식도 바꾸지 않아요. pirep을 지워도 문서는 그대로 남아요.

✓
계정이 없어요
가입하지 않고 바로 폴더를 열면 시작해요.
✓
마크다운 그대로예요
읽은 위치와 버전 기록만 따로 저장하고, 문서 자체는 건드리지 않아요.
✓
다른 앱과 같이 써요
같은 폴더를 편집기나 Git으로 함께 다뤄도 돼요. 바뀌면 pirep이 알려줘요.

INSTALL

폴더 하나만 열면 시작해요

설치하고 마크다운이 있는 폴더를 고르면 바로 읽을 수 있어요. 가입 절차는 없어요.

TERMINAL
$ curl -fsSL https://pirep.pages.dev/install.sh | sh $ open -a pirep

터미널이 싫으면 릴리스 페이지에서 dmg를 받으세요. dmg로 받은 앱은 첫 실행 때 시스템 설정 > 개인정보 보호 및 보안에서 한 번 열어 줘야 해요.

pirep 사용법

폴더를 열고, 읽지 않은 것만 읽는 앱이에요. 이 문서는 화면에 있는 것을 그대로 설명해요.

ON THIS PAGE
시작하기 읽을 것 목록 바뀐 내용 파일 종류 단축키 설정

시작하기

가입 절차는 없어요. 마크다운이 있는 폴더를 하나 고르면 그게 Base가 돼요.

1
pirep을 설치해요
내려받은 파일을 열어 응용 프로그램 폴더로 옮겨요.
2
폴더를 골라요
처음 열면 새 Base를 만들거나 이미 마크다운이 있는 폴더를 고를 수 있어요.
3
색인이 끝나면 읽기 시작해요
폴더를 한 번 훑어서 문서 목록을 만들어요. 파일은 바꾸지 않아요.

Base는 나중에 설정 → Base에서 바꿀 수 있어요. 여러 폴더를 동시에 열 수는 없어요.

읽을 것 목록

사이드바는 두 가지 모드예요. QUEUE는 읽을 것만 보여주고, FILES는 폴더 구조를 그대로 보여줘요.

UPDATES 지난번에 읽은 뒤로 내용이 바뀐 문서예요. 옆에 지금 버전과 지난 수정 시각이 붙어요.
UNREAD 아직 한 번도 읽지 않은 문서예요. 읽으면 목록에서 빠져요.
PINNED 직접 고정한 문서예요. 읽어도 남아 있어요.
RECENT 최근에 열어 본 문서예요. 읽음 여부와 관계없이 쌓여요.

사이드바 폭은 끌어서 조절해요. 창이 좁아지면 사이드바가 덮개로 열려요.

바뀐 내용

문서마다 마지막으로 읽은 버전을 기억해요. 그 버전과 지금 파일이 다르면 업데이트로 알려줘요.

HOW IT DECIDES
✓ 내가 앱에서 읽으면 그 버전이 「읽은 버전」이 돼요.
✓ 다른 편집기나 AI 도구가 파일을 저장하면 새 버전이 생겨요. 저장이 몰릴 때는 0.4초 기다렸다가 한 번만 기록해요.
✓ 읽은 버전과 지금 버전 사이에서 바뀐 줄만 보여줘요. 반영하거나 되돌릴 때까지 목록에 남아요.

⌘U를 누르면 바뀐 문서만 모아서 한꺼번에 처리할 수 있어요. 버전 기록은 설정 → 버전 기록에서 보관 기간을 정해요.

파일 종류

파일명 옆 칩의 색은 확장자가 아니라, pirep이 그 파일로 무엇을 할 수 있는지를 나타내요.

MD NATIVE
pirep의 형식이에요. 읽고, 편집하고, 버전을 추적해요.
md · markdown · mdx
PDF READABLE
앱 안에서 볼 수 있어요. 편집은 안 되지만 버전은 추적해요.
html · pdf · csv · txt · json · yaml · png · jpg · svg
PPTX· OPAQUE
앱에서 열 수 없어요. 누르면 원래 쓰던 앱으로 넘겨줘요.
pptx · docx · xlsx · zip · 그 외 전부

설정

탭 여덟 개예요.

Appearance 테마, 본문 폭, 사이드바 기본 모드, 화면 언어를 정해요.
Editor 줄바꿈 기준, 자동 저장, 붙여넣기 처리를 정해요.
Base 지금 열려 있는 폴더를 확인하고 다른 폴더로 바꿔요.
Version history 스냅샷을 남길지, 얼마나 보관할지 정해요. 끄면 읽음 추적이 멈춰요.
Templates 새 노트에 쓸 형식과 자동 생성 규칙을 관리해요.
Account & Sync Base가 이미 동기화되는 위치인지 알려줘요. pirep은 파일을 서버로 보내지 않아요.
Shortcuts 위 표와 같은 전체 키맵이에요.
About 버전과 업데이트 확인이에요.

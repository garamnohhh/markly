# Markly — 사용자(너)가 결정/제공해야 하는 항목

> 내가 임의로 못 정하는 것들. 디자인 원천(`design_handoff_markly/*.dc.html`)에
> 없거나, 제품 방향 결정이 필요한 것. 정해주면 내가 구현.

## 1. 폴더(디렉토리) 뷰 화면 — 미존재
- 타이틀바 경로 `로고 › Project › test`에서 **`Project`(폴더) 클릭 시 갈 화면이 디자인에 없음.**
- 현재: 폴더 세그먼트 클릭하면 아무 동작 안 함(`title="Folder view (coming soon)"`).
- 결정 필요:
  - (a) 폴더 안 문서 목록 화면을 새로 만들까? → 디자인 시안 주거나 "Knowledge Inbox 비슷하게" 같은 방향 지시
  - (b) 폴더 클릭 = 사이드바 Files 탭에서 해당 폴더 열기/스크롤 (화면 안 만들고 사이드바만 연동)
  - (c) 폴더는 클릭 불가(텍스트만) 유지

## 2. 편집 모드 = 전부 raw — 결정됨 ✅
- 너 요청대로 단순화: 편집 모드 = 문서 전체 raw markdown(플레인 CodeMirror), 끝나면 렌더.
- ixora 라이브프리뷰 제거. 좌측 잉크 보더 + mono(디자인). 편집→읽기 시 보던 헤딩 위치로 복귀.

## 6. 창 모서리(rounded corners) — 트레이드오프
- 정렬 확실히 하려고 `decorations:false` + 커스텀 신호등 사용 → 창 모서리가 **각짐**(네이티브 라운드 사라짐).
- 라운드 복원하려면 `transparent:true` + CSS border-radius 필요(macOSPrivateApi, 사이드이펙트 가능).
- 결정 필요: 각진 창 OK인지, 라운드 복원할지.

## 7. 신호등 색 — 확인
- 디자인 mockup은 회색 점(=비포커스 상태). 나는 표준 macOS 컬러(빨/노/초)로 구현(포커스 상태 = 정상).
- 회색 고정 원하면 알려줘.

## 3. 타이틀바 'More(⋯)' 메뉴 — 액션 미정
- 디자인(Markly.dc.html)에 우측 끝 More(점 3개) 메뉴 있음. 현재 미구현(액션 없음).
- 결정 필요: More에 들어갈 항목(예: 문서 삭제/이름변경/내보내기/pin) 목록 알려주면 추가.

## 4. 스크롤 위치 read↔edit 동기화 — 한계 안내
- 읽기(렌더된 높이)와 편집(raw 소스 높이)은 본질적으로 레이아웃 높이가 달라
  스크롤바 위치가 100% 일치 불가. 현재 **스크롤 비율(%) 보존**으로 근사.
- 더 정밀하게(현재 보던 문단 기준 앵커 정렬) 원하면 별도 작업 필요. 필요하면 지시.

## 5. 제목 정책 — 결정됨 ✅
- 파일명 기준(확장자 제외). 전 화면(Queue/타이틀바/Files/Inbox/Diff/팔레트) 일관 적용 완료.
